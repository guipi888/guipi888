## 重点项目

### [video-skill-router](https://github.com/guipi888/video-skill-router) — 视频创作技能路由器

AI video & animation skill router（视频/动画创作元技能）：你说一句需求，它自动判定视频类别（商业宣传/知识科普/其他）→ 优先匹配本地已装技能 → 本地没有就按类别发现并下载安装 Manim/Remotion/Lottie 等技能包 → 编排执行输出成片 → 最后问你要保留还是卸载所装技能。

适合：想做视频但不知道用什么工具的人。内置 11 个 GitHub 实证技能包精选目录，安装卸载全程 git 快照可回滚。

```bash
git clone https://github.com/guipi888/video-skill-router.git ~/.workbuddy/skills/video-skill-router
```
